# Recursos para Google Play

Esta carpeta contiene los recursos necesarios para publicar la aplicación en Google Play.

## Icono para Google Play

El archivo `icon.svg` es un archivo vectorial que contiene el diseño del icono de la aplicación para Google Play. Este archivo debe convertirse a PNG con una resolución de 512x512 píxeles antes de subirlo a Google Play.

### Instrucciones para convertir SVG a PNG

Puedes utilizar alguna de las siguientes herramientas para convertir el archivo SVG a PNG:

1. **Inkscape (Gratuito):**
   - Abre el archivo SVG en Inkscape
   - Ve a Archivo > Exportar PNG
   - Configura la resolución a 512x512 píxeles
   - Exporta el archivo

2. **Adobe Illustrator:**
   - Abre el archivo SVG en Adobe Illustrator
   - Ve a Archivo > Exportar > Exportar como
   - Selecciona formato PNG
   - Configura la resolución a 512x512 píxeles
   - Exporta el archivo

3. **Herramientas online:**
   - [Convertio](https://convertio.co/svg-png/)
   - [CloudConvert](https://cloudconvert.com/svg-to-png)
   - [SVG2PNG](https://svgtopng.com/)

### Requisitos de Google Play

Google Play requiere un icono de alta resolución (512x512 píxeles) para mostrar en la tienda. Este icono debe ser un archivo PNG de 32 bits (con canal alfa).

### Diseño del icono

El icono representa el logo de la aplicación Taxxi con las letras "GTx" (G en rojo, Tx en negro) sobre un fondo blanco circular, con un fondo que simula una carretera y cielo, dando contexto al servicio de taxi.
